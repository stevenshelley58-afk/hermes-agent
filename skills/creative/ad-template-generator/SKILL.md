# Ad Template Generator entry point

Read `/projects/frank/docs/standards/engineering-rules.md`,
`/projects/frank/AGENTS.md` and
`/projects/frank/docs/AD_TEMPLATE_GENERATOR.md`.

That guide owns acceptance policy, run control, release verification and approval
boundaries. Hermes owns execution; Frank forwards commands and displays evidence.
Use the controller's supported operations rather than simulating run state.

For output review and annotation corrections, also read the sibling skill
`../ad-output-qa/SKILL.md` and its referenced checklist. The generator's pinned
checklist and executable output checks must apply to the current render; merely
loading a skill is not evidence of a successful check. Preserve scores, history,
frozen routes, retry budgets and the separate operator publishing decision.
